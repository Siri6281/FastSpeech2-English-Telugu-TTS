# English

Dataset: English Svarah. Dataset source: https://www.kaggle.com/datasets/sirichandana6281/fastspeech2-english-training

The inspected preprocessed split contains 2,815 training and 557 validation entries with matching mel, pitch, energy and duration feature files. The dataset archive is not included in this repository.

Five English test audio files are stored under Results/English/test_generated_audios. Their provenance as FastSpeech2 outputs is not verified. No recoverable trained English acoustic checkpoint or verified training/validation curves are available.
